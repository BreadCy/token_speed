# TokenSpeed 原生悬浮窗极简 UI 设计

## Goal

重设计 macOS/Windows 的 TokenSpeed 桌面悬浮窗，让实时速度成为唯一主视觉，同时保留 Agent、模型、最近一轮、会话平均值、精确/估算和本地会话状态。

## 约束

- 不改采集器、报告结构、配置格式和离线读取边界。
- 不增加依赖；复用现有 egui/eframe。
- 不使用渐变、重阴影、emoji 或依赖字体覆盖的图标。
- 中文与数字必须在 macOS、Windows 有明确字体回退。
- 精确/估算必须以文字呈现，不能只靠颜色区分。

## 视觉系统

- 背景：`#F7F6F3`；内容层：`#FFFFFF`；主文字：`#171717`；次文字：`#77736C`；分隔线：`#E7E5E0`。
- 唯一状态强调色：在线/有数据使用低饱和绿色；生成中使用琥珀色；错误保持深灰文字。
- 系统字体：macOS 优先 PingFang SC，Windows 优先 Microsoft YaHei UI；等宽字体用于速度和 token 数字。
- 容器圆角 10px，边框 1px；控件使用 4–6px 小圆角。

## 布局

窗口默认约 `400 × 216`，最小尺寸保持可读性。

1. 顶栏：状态圆点、Agent 名称、设置按钮。
2. 主指标：大号等宽速度值，右侧小号 `tok/s` 与“精确/估算”。
3. 详情行：模型、最近一轮、会话加权平均。
4. 最近轮次：默认收起的一行摘要，展开后显示最近 10 轮细线列表。
5. 底部：本地会话、未检测到匹配会话、生成中等状态文本。

## 行为

- 保持 250ms UI 重绘与后台监视线程。
- 保持设置窗口、Agent 单选、项目范围和托盘入口行为。
- 生成中继续保留上一完整轮结果，并在状态行明确说明。
- 无数据时显示短文本，不渲染空卡片或占位图形。

## 验收

- `cargo test` 通过。
- macOS/Windows 字体路径不再把中文显示为方框；无字体文件时回退到 egui 默认字体。
- 主指标、精确/估算、模型、最近一轮、会话平均值和状态在窗口内不截断。
- 视觉上无渐变、重阴影和大面积高饱和色块。

## HTML 视觉对齐修订（2026-09-06）

根据 `tokenspeed.html` 的演示窗口，将原定暖白纸面方案调整为同源深色窗口：背景使用 `#1D1E20`，内容层 `#242529`，列表层 `#191A1D`，文字 `#EBEBEE`，弱文字 `#9D9DA4`，绿色仅用于 LIVE/精确状态，琥珀色用于生成中/估算状态。主指标、LIVE 徽章、模型速度/会话加权平均和“最近 10 轮”列表沿用 HTML 的顺序与间距；本地数据和交互保持不变。
